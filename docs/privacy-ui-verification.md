# 개인정보 안내 UI 검증 기록

`/privacy`와 `/landing`을 1280×720 데스크톱 뷰포트에서 확인했다.

- `/privacy`: 제목, 공개 전 확인 안내, 개인정보 수집·이용·AI 외부 서비스·보관 및 파기·이용자 권리·문의 섹션이 읽기 가능한 폭으로 표시됨.
- `/landing`: footer에 `개인정보 처리방침` 링크가 표시되고 `/privacy`로 연결되는 구조를 확인함.
- 결제 신청 폼에는 개인정보 안내 확인 체크박스와 처리방침 링크가 추가되며, 동의 전 신청 버튼이 비활성화되는 구조임.
- `pnpm check`, `pnpm test`, `pnpm build`가 모두 성공했으며 20개 테스트 파일, 38개 테스트가 통과함.

본 문구는 MVP 기능 기준 초안이며 실제 공개 전 운영자명, 사업자 정보, 문의처, 보관 기간, 위탁·국외 이전 조건은 운영 계약과 법률 검토 결과로 확정해야 한다.

추가로 모바일 390×844에서 `/privacy`를 확인했다. 긴 문단이 화면 밖으로 넘치지 않고 각 섹션이 세로로 읽히며, 상단 랜딩 복귀 링크와 하단 footer가 표시된다. 페이지는 단일 `h1` 제목과 순차적인 `h2` 섹션 제목을 사용하고, 랜딩·처리방침 링크는 실제 anchor 요소로 키보드 접근이 가능하다. 청구서 신청 동의 체크박스는 `required`로 설정되어 동의 전 제출을 막는다.

최신 변경 후 모바일 390×844에서 `/landing`과 `/privacy`를 다시 확인했다. 랜딩의 카카오 시작 CTA 아래 카카오 계정 식별자·기본 프로필 정보 처리 안내와 개인정보 처리방침 링크가 화면 폭 안에서 표시된다. 개인정보 처리방침은 상단 복귀 링크, 단일 제목, 순차 섹션, 하단 문의 섹션이 모두 세로 흐름으로 표시된다. 개인정보 링크에는 `focus-visible` ring 스타일이 적용되며, 결제 폼 체크박스에도 동일한 가시적 포커스 스타일이 적용된다. 탭 순서는 문서 흐름상 복귀 링크→처리방침 링크→결제 동의 체크박스→신청 버튼 순서로 접근 가능하다.
