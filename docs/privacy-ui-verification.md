# 개인정보 UI 검증 기록

기준 버전: blogmate 개인정보 처리방침 개편본

## 확인 범위

모바일 390×844 뷰포트에서 `/privacy`와 `/landing`을 전체 페이지로 확인했다. 개인정보 처리방침은 참고 SaaS의 쇼츠·추천인·TTS·수익공유 항목을 제거하고 blogmate의 카카오 로그인, 브랜드 자료, URL 분석, AI 처리, 청구서 신청, 구독 승인, 접속 로그 및 이용자 권리 항목으로 재구성되어 표시된다.

## 결과

`/privacy`는 12개 독립 섹션과 각 섹션의 목록을 세로로 표시하며, 긴 문장이 화면 밖으로 넘치지 않는다. 운영자·사업자 정보, 구체적 보관 기간, 외부 수탁자와 국외 이전 조건은 실제 계약 및 공개 정보 확정 전의 초안임을 상단과 하단에 표시한다. `/landing`은 기존의 공감형 카피와 CTA를 유지하면서 개인정보 안내 링크를 제공한다.

개인정보 처리방침 링크는 실제 anchor 요소이며 `focus-visible` 링 스타일을 사용한다. 카카오 로그인 CTA 주변에는 계정 식별자·기본 프로필 정보 처리 안내가 표시되고, 청구서 신청에는 필수 동의 체크박스와 처리방침 링크가 제공된다.

## 공개 전 확인 필요

운영자명, 사업자등록번호, 주소, 개인정보 보호책임자와 문의처, 실제 DB·스토리지·AI·결제 수탁자, 국외 이전 국가, 보유 기간은 실제 운영 환경과 계약을 기준으로 확정해야 한다. 본 문서는 법률 자문이 아닌 공개 전 작업 초안이다.

추가로 데스크톱 1280×720에서 `/privacy`를 전체 페이지로 확인했다. 12개 목록형 섹션이 중앙 콘텐츠 폭 안에 정렬되고, 섹션 간 구분선·본문 줄간격·상단 안내 박스가 읽기 흐름을 유지한다. 긴 항목은 카드 폭 안에서 자연스럽게 줄바꿈되며 수평 스크롤이나 레이아웃 겹침이 보이지 않았다.
