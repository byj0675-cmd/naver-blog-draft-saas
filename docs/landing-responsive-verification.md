# 랜딩페이지 반응형 검증 기록

검증 대상은 `/landing` 경로이며, 개편된 전환형 카피와 생성 이미지가 화면 크기에 따라 정상적으로 배치되는지 확인했다.

| 뷰포트 | 결과 | 확인 내용 |
|---|---|---|
| 데스크톱 1280×720 | 통과 | 공감형 히어로 카피와 히어로 이미지가 좌우 분할로 배치되고, 문제 심화 섹션·해결책 카드·가격표·FAQ·최종 CTA가 순서대로 노출됨 |
| 모바일 390×844 | 통과 | 긴 훅 카피가 화면 밖으로 넘치지 않고 세로 흐름으로 전환되며, 히어로 이미지·문제 해결 비교 이미지·가격 카드·FAQ가 읽기 가능한 폭으로 표시됨 |

추가로 `pnpm check && pnpm test && pnpm build`를 실행했으며 타입 검사와 프로덕션 빌드가 성공했고, 20개 테스트 파일의 38개 테스트가 통과했다. 랜딩페이지의 자동 발행 오해를 줄이기 위해 “고객이 직접 검수한 뒤 네이버에 발행”한다는 안내도 해결책 섹션과 FAQ에 포함했다.

## 메인 대시보드 카피 검증

대시보드 `/`의 메인 문구를 `우리 매장다운 글을 / 꾸준히 쌓아보세요.`로 수정했다. 모바일 390×844와 데스크톱 1280×720에서 두 줄 구조가 자연스럽게 유지되고, 강조 색상·서브 카피와 의미가 연결된다. 기존의 추상적인 `다시, 좋은 글을 / 꾸준히.`보다 브랜드별 콘텐츠를 꾸준히 쌓는 서비스 가치가 직접적으로 전달된다.

## 대시보드 비AI형 UI 개편 검증

대시보드 Overview를 한국어 업무 용어 중심으로 정리하고, 장식적인 Sparkles 아이콘·AI 생성 중 문구·영문 라벨을 줄였다. 브랜드 메모 패널은 어두운 강조 카드에서 밝은 문서형 패널로 바꾸고 `브랜드 메모`, `글쓰기 기준을 정리했어요`, `참고한 글`처럼 실제 운영 맥락의 표현을 사용했다. 초안 생성 버튼은 `초안을 준비하는 중...`, `1건 차감`으로 변경했다.

| 뷰포트 | 결과 | 확인 내용 |
|---|---|---|
| 데스크톱 1280×720 | 통과 | 한국어 네비게이션, 생성량·SEO·활성 브랜드 카드, 최근 초안과 브랜드 메모가 균형 있게 배치됨 |
| 모바일 390×844 | 통과 | 상단 헤더와 카드가 화면 폭 안에 유지되고, 메인 문구·사용량 카드·업무형 라벨이 자연스럽게 세로 흐름으로 표시됨 |

## 다음 작업 우선 구조 검증

대시보드 상단에 `지금 이어서 할 일` 영역을 추가해 검토 중인 초안, 브랜드 자료 추가, 구독 상태 확인을 사용량 카드보다 먼저 노출했다. 각 항목은 해당 화면으로 바로 이동하는 버튼이다.

| 뷰포트 | 결과 | 확인 내용 |
|---|---|---|
| 데스크톱 1280×720 | 통과 | 세 가지 우선 작업이 한 줄 카드로 정렬되고 기존 사용량 카드보다 위에 배치됨 |
| 모바일 390×844 | 통과 | 우선 작업 카드가 세로로 자연스럽게 쌓이며 제목·설명·이동 화살표가 화면 안에 표시됨 |
