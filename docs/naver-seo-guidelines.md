# 네이버 검색 콘텐츠 적용 기준

최종 확인일: 2026-08-27

이 문서는 blogmate 초안 생성 기준을 설계하기 위해 네이버 서치어드바이저 공식 가이드를 확인하고 정리한 내부 참고 문서입니다. 검색 상위 노출을 보장하는 규칙이 아니라, 검색 사용자를 위한 품질과 구조를 높이는 기준으로 사용합니다.

## 적용 원칙

1. 콘텐츠와 직접 관련된 정확하고 고유한 제목과 설명을 작성합니다. 관련 없는 인기 검색어를 넣거나 동일 단어를 의미 없이 반복하지 않습니다.
2. 단순한 정보 나열보다 운영자의 실제 경험·전문성·구체적인 사례·정확한 수치를 우선합니다.
3. 사이트와 글의 주제를 일관되게 유지하고, 제품·서비스 소개도 과장 없이 사실과 조건을 명확히 합니다.
4. AI 초안을 그대로 게시하지 않고 운영자의 경험과 관점을 보완합니다. 출처를 인용하면 원문과 원작자를 표시합니다.
5. 제목·소제목·문단·번호를 사용해 독자가 핵심 정보를 빠르게 찾도록 구성합니다. 긴 문장은 나누고 중요한 정보는 이미지 안에만 넣지 않습니다.
6. 가격·정책·법규·영업시간 등 변경 가능한 정보는 최신 상태를 확인한 뒤 작성합니다. 낚시성 제목과 과도한 키워드 반복은 사용하지 않습니다.
7. 키워드는 검색 의도와 실제 사업 정보에 맞춰 제목·도입부·소제목·본문·마무리·해시태그에 자연스럽게 분산합니다. 고정 반복 횟수나 상위 노출을 보장하는 공식 비율은 적용하지 않습니다.
8. 생성 화면은 제목 후보 3개를 제공하고, 후보별 검색 의도와 포함 키워드를 표시합니다. 사용자가 하나를 선택한 뒤 본문을 생성·편집하도록 합니다.

## 유의사항

네이버 공식 가이드는 검색 결과의 상위 노출을 보장하지 않는다고 안내합니다. blogmate의 SEO 점수는 글의 구조·키워드 자연스러움·가독성·검색 의도 충족 여부를 점검하는 내부 보조 지표이며, 네이버의 실제 순위나 노출을 예측하는 값으로 표시하지 않습니다.
