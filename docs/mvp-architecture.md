# 블로그메이트 AI MVP 아키텍처

## 1. 제품 운영 모델

고객은 카카오 간편가입으로 계정을 만들고, 자신의 브랜드 프로필과 톤 샘플을 등록합니다. 생성 요청은 서버에서 월간 한도와 초안별 재생성 한도를 먼저 검증한 뒤 AI에 전달합니다. 생성이 성공한 경우에만 사용량을 확정하고, 고객은 초안을 직접 검수·수정·복사하여 네이버 블로그에 수동 발행합니다. 네이버 자동 발행은 MVP 범위에서 제외합니다.

## 2. 구성 요소

| 계층 | MVP 구성 | 책임 |
|---|---|---|
| Web UI | React + Tailwind + tRPC client | 브랜드·생성·편집·SEO·구독·관리자 화면 |
| 인증 | Kakao OAuth 2.0 | 카카오 로그인, 사용자 식별자 발급, 세션 생성 |
| API | Express + tRPC | 인증, 생성, 사용량, 결제 승인, 초안 저장 |
| 데이터베이스 | MySQL/TiDB + Drizzle | 사용자·브랜드·톤·초안·사용량·결제 상태 저장 |
| 텍스트 AI | DeepSeek API adapter | 초안·톤 분석·SEO 개선안 생성 |
| 이미지 AI | 서버 이미지 생성 helper | 썸네일·본문 이미지 생성 |
| 결제 MVP | 수동 입금 신청 | 신청·확인·승인·거절·이용권 활성화 |
| 추후 결제 | 결제선생 adapter | 보증금 및 API 키 확보 후 교체 |

## 3. 카카오 간편가입 흐름

1. 브라우저가 `GET /api/auth/kakao/start`로 이동합니다.
2. 서버가 `https://kauth.kakao.com/oauth/authorize`로 리다이렉트하며 `client_id`, `redirect_uri`, `response_type=code`, `state`를 전달합니다.
3. 카카오가 `GET /api/auth/kakao/callback?code=...&state=...`로 돌아오면 서버가 토큰 엔드포인트에서 액세스 토큰을 교환합니다.
4. 서버가 `GET https://kapi.kakao.com/v2/user/me`를 호출해 카카오 고유 ID와 동의된 프로필 정보를 가져옵니다.
5. `users.openId`에 `kakao:{id}`를 저장하거나 기존 사용자를 갱신하고, 기존 세션 쿠키를 발급합니다.
6. 실패·state 불일치·동의 정보 부족은 로그인 실패 화면으로 보내며, 액세스 토큰은 DB에 저장하지 않습니다.

필요한 운영 값은 `KAKAO_REST_API_KEY`, `KAKAO_CLIENT_SECRET`(사용하는 경우), `KAKAO_REDIRECT_URI`입니다. 카카오 개발자 콘솔에서 Redirect URI와 동의항목을 먼저 등록해야 합니다.

## 4. 사용량 정책

MVP 기본 플랜은 고객별 캘린더 월 12건입니다. `usageCounters(userId, periodKey)`의 유니크 키를 이용해 월별 카운터를 분리하고, SQL 조건부 증가로 동시 요청에서도 12건을 넘지 않도록 합니다. 초안 재생성은 `draftHistories.regenerationCount < 3` 조건으로 초안별 최대 3회로 제한합니다. AI 호출이 실패하면 예약한 월간 카운터와 재생성 카운터를 다시 줄입니다.

정책상 재생성도 새로운 AI 호출이므로 월 12건 카운터에 포함합니다. 화면에는 `이번 달 7/12건`, `이 초안 재생성 1/3회`를 함께 표시해야 합니다.

## 5. 수동 결제 승인

`paymentRequests`는 신청자, 플랜, 금액, 입금자명, 상태, 관리자 메모와 검토 시각을 저장합니다. 고객이 신청하면 `pending`으로 생성되고, 관리자가 입금 확인 후 승인하면 구독을 `active`로 만들고 해당 플랜의 월 생성 한도를 활성화합니다. 거절하면 `rejected`와 사유를 저장합니다. 승인·거절 API는 `users.role=admin`인 사용자만 호출할 수 있습니다.

## 6. DeepSeek 비용 최적화 시뮬레이션

공식 문서의 현재 표기 가격은 1백만 토큰 기준입니다. `deepseek-v4-flash`는 비피크 기준 입력 캐시 미스 $0.22, 출력 $0.66이며, 피크 기준 입력 $0.44, 출력 $1.32입니다. 캐시 히트 입력은 각각 $0.007, $0.014입니다. 가격은 변경될 수 있으므로 운영 전 공식 가격표를 재확인합니다. [1]

고객 1곳이 월 12건을 생성한다고 가정하고, 글 1건당 입력 8,000토큰·출력 2,500토큰, 톤 분석 월 1회 입력 25,000·출력 3,000, SEO 분석 월 12회 입력 1,500·출력 500, 재생성 2회를 평균으로 잡았습니다.

| 사용 구간 | 입력 토큰 | 출력 토큰 |
|---|---:|---:|
| 초안 12건 | 96,000 | 30,000 |
| 톤 분석 | 25,000 | 3,000 |
| SEO 12회 | 18,000 | 6,000 |
| 재생성 2회 | 16,000 | 5,000 |
| **월 합계** | **155,000** | **44,000** |

비피크 캐시 미스 단가를 보수적으로 적용하면 계산은 `0.155 × $0.22 + 0.044 × $0.66 = $0.0637`입니다. 원화 환율과 부가 비용을 넉넉하게 반영해도 고객 1곳당 텍스트 AI 예산은 우선 **월 수백 원~수천 원 범위**로 잡을 수 있습니다. 가장 큰 비용 변동 요인은 긴 톤 샘플, 재생성 남용, 이미지 생성, 실패 재시도입니다.

최적화 규칙은 다음과 같습니다. 브랜드 톤 프로필은 원문 전체가 아니라 구조화된 JSON 지표를 저장하고 이후 프롬프트에 짧게 삽입합니다. 시스템 프롬프트는 고정해 캐시 효율을 높입니다. 초안은 한 번에 JSON으로 생성하고, SEO 점검은 전체 초안이 아니라 제목·도입부·소제목·키워드 통계를 우선 전달합니다. 재생성은 전체 글이 아니라 “본문만 다시 작성” 같은 범위를 선택하게 합니다. 이미지 생성은 텍스트 생성과 별도 크레딧으로 제한합니다.

## 7. 핵심 환경변수

| 변수 | 용도 | 상태 |
|---|---|---|
| `KAKAO_REST_API_KEY` | 카카오 OAuth client_id | 사용자 발급 필요 |
| `KAKAO_CLIENT_SECRET` | 카카오 보안 강화 설정 시 | 선택 또는 발급 필요 |
| `KAKAO_REDIRECT_URI` | OAuth callback 주소 | 배포 도메인 확정 필요 |
| `DEEPSEEK_API_KEY` | DeepSeek 서버 호출 | 사용자 발급 필요 |
| `PAYSSAM_API_KEY` | 결제선생 추후 자동화 | 보증금·계약 후 |
